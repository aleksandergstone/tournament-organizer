# Tournament Organizer 1.8.0

**November 10, 2026**

## Stabilization

- Restored the complete standard tournament creation wizard.
- Added the sailing presets referenced by the current discipline catalogue.
- Updated the mode catalogue checks and filled in the missing English, Polish,
  German and Spanish preset descriptions.
- Added a sailing-specific event wizard, boat/class management, race scheduling
  and results, plus boat and team series standings.
- Synchronized release metadata for version 1.8.0.

## Sailing scope

The sailing flow supports fleet racing, match racing as repeated pairwise
fixtures, and team racing with team-assigned boats and team standings. It
includes event/class setup, race scheduling, race and result editing, scoring,
discarded-series points and sailing document management.

Flights, handicap/time-corrected scoring, and automatic sailing-document
generation are not implemented. The wizard does not expose unsupported options.
