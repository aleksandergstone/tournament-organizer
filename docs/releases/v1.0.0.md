# Tournament Organizer 1.0.0

Released 2026-09-27 · [Download](#download) · [Changelog](../CHANGELOG.md)

The first public release of a free, offline desktop app for running tournaments and leagues.

## Highlights

- **Nine competition formats** — single elimination, double elimination (winners + losers bracket,
  grand final and conditional reset), round robin, Swiss, groups + knockout, league season,
  team and individual match events, and a custom schedule.
- **Brackets that stay correct.** Every result edit re-resolves the bracket: winners advance and
  results that are no longer possible are cleared instead of silently kept.
- **Result entry built for a venue** — two score fields and a button, plus walkover, unfinished
  and interrupted states, keyboard navigation (`j`/`k`, `/`, `Enter`).
- **Standings with your rules** — points, tiebreak order, group tables and qualifier selection
  that seeds the knockout stage.
- **Offline and local-first.** No account, no server, no telemetry. Projects autosave to the
  device and are exported as a single portable `.top.json` file.
- **Recovery built in** — undo/redo across the session, validated import, and a printable summary.

## Fixes

- Double elimination for 4–64 participants: the losers bracket is now generated with correct
  round sizes and feeds, verified by automated tests across every supported field size.
- Corrected a case where a fully resolved derived match could keep a placeholder *bye* status and
  stall the next round.

## Known limitations

- Installers are **not code-signed** and the macOS app is not notarized (see Installation).
- Bracket formats are tested up to 64 participants; round robins and leagues scale further but
  grow quickly in match count.
- The app is available in English only.

## Installation

- **Windows:** run the installer and follow the prompts. The installer is not code-signed, so
  Windows shows “Unknown publisher” — choose *More info → Run anyway*.
- **macOS:** open the disk image and drag the app into Applications. It is not notarized, so the
  first launch needs right-click → *Open*.
- **Linux:** `chmod +x Tournament-Organizer-1.0.0-linux-x86_64.AppImage` and run it.

## Upgrading

- First release — no upgrade path needed yet. Later releases will keep existing project files
  readable; the app migrates older files automatically on import.
- To move projects to another machine: `Export → Save .top.json`, then `Import / Recovery`.
