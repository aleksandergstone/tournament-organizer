# Tournament Organizer 1.2.0

Released 2026-09-28 · [Download](#download) · [Changelog](../CHANGELOG.md)

Tournament paperwork: branded, print-ready documents instead of a generic summary
page. Everything is still produced on the machine — no service, no account.

## Highlights

- **Output & branding screen** (was "Export") — pick what to produce, see a live
  preview of the finished page, then save it as PDF, print it, or save the same
  document as CSV. The preview is the exact document that gets printed.
- **Six export variants** — standings, match list, schedule/timetable, bracket,
  group tables, and an organizer pack (event information + table + match list +
  timetable + bracket in one document).
- **Real PDF export** — an A4 PDF with repeating table headers, a running footer
  and "Page X of Y". In a browser the same document goes to the print dialog.
- **Branding** — event title, competition subtitle, season/edition label, event
  logo, optional sponsor logo, header line, footer text, a notes/disclaimer block
  and an accent colour. Branding is part of the project: saved, exported, synced
  and used by every document.
- **Organizer-grade output** — one timetable per event day ordered by time and
  court, consecutive match numbers, walkovers naming the winner, byes left out,
  withdrawn participants marked, and the tie-break order printed under every
  table so a disputed position can be settled from the paper.

## Known limitations

- Installers are **not code-signed** and the macOS app is not notarized (see
  Installation).
- The printed tables are generated in the language the app runs in — round names
  are written when the bracket is generated.

## Installation

- **Windows:** run the installer and follow the prompts. The installer is not
  code-signed, so Windows shows “Unknown publisher” — choose *More info → Run
  anyway*.
- **macOS:** open the disk image and drag the app into Applications. Not
  notarized: the first launch needs right-click → *Open*.
- **Linux:** `chmod +x Tournament-Organizer-1.2.0-linux-x86_64.AppImage` and run it.

## Upgrading

- Project files from earlier versions open unchanged; branding is an optional
  addition to the project file.
- To move projects to another machine: `Export → Save .top.json`, then
  `Import / Recovery`.
