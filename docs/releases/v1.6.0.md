# Tournament Organizer 1.6.0

Released 2026-10-03 · [Download](#download) · [Changelog](../CHANGELOG.md)

A release about *sharing*. A tournament can be put on a public website for
spectators to follow live, and taken down again — while the tournament itself
never leaves your computer first.

## Highlights

- **Online preview, off by default.** One switch turns it on. Nothing is sent
  until you ask for it, because an accidental publish is visible to the whole
  internet and a tournament that is only run on one laptop has no business being
  online at all.
- **The link is the event's name.** "Mistrzostwa Klubu" becomes
  `tooboxplatform.online/mistrzostwa-klubu`. If a name is already taken, a few
  more characters are added automatically — you are never asked to invent an
  address for your own event.
- **Choose who can see it.** *Anyone with the link* — shareable but never
  advertised. Or *anyone, including search engines* for an event you want found.
- **Stop sharing in one click.** The link stops working immediately rather than
  quietly serving results that are no longer true.
- **The website draws, the app decides.** The public site renders a precomputed
  snapshot and never calculates a table of its own, so a rule you change cannot
  make two screens disagree.
- **Only what belongs on a match sheet.** Participants, results and standings go
  out. Your tags, audit history and tournament rules stay on your machine.

## Installation

- **Windows:** run the installer and follow the prompts. It is not code-signed, so
  Windows shows "Unknown publisher" — choose *More info → Run anyway*. If an
  older version is installed, uninstall it first: Windows lists it separately and
  the new installer will not overwrite it cleanly.
- **Android:** install the APK over the previous one. It is signed with the same
  key as earlier versions, so it updates in place and your projects are kept.

## Publishing a tournament

Sharing is opt-in and needs no account anywhere:

1. Open **Online preview** in the sidebar and turn on the switch.
2. Choose who can see the link.
3. Press **Share** and give the link to whoever should see it.

To stop, press **Stop sharing**.

The link follows the tournament's name, so rename the event and the link changes
with it — you never type an address yourself.

## Upgrading

- Existing projects open unchanged. Sharing is new and off until you turn it on,
  so nothing is published until you ask for it.
- A tournament that is only ever used offline behaves exactly as before: no token,
  no address, no internet connection required.
- To move projects to another machine: `Export → Save .top.json`, then
  `Import / Recovery`.

## Known limitations

- Installers are **not code-signed**.
- The publish token is stored in the app's settings, which means it is as
  protected as the profile directory it lives in. On a shared computer, that is
  worth thinking about.
- Sharing is manual: results update when you press **Share**. There is no
  automatic republishing yet, so a match scored live is not on the page until you
  send it again.
- Tables scroll inside their own frame on a phone; they are not reshaped into cards.
