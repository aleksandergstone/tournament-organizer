# Tournament Organizer 1.6.0

Released 2026-10-04 · [Download](#download) · [Changelog](../CHANGELOG.md)

A release about *sharing*. A tournament can be put on a public website for
spectators to follow live, and taken down again — while the tournament itself
never leaves your computer first.

## Highlights

- **Online preview, off by default.** One button turns it on. Nothing is sent
  until you press it, because an accidental publish is visible to the whole
  internet and a tournament that is only run on one laptop has no business being
  online at all.
- **Nothing to type.** No address, no account, no key to paste — the site and the
  publish key ship with the app. Set your own token only if you run your own
  website.
- **The link is the event's name.** "Mistrzostwa Klubu" becomes
  `tooboxplatform.online/mistrzostwa-klubu`. If a name is already taken, a few
  more characters are added automatically — you are never asked to invent an
  address for your own event. The address is on screen before anything is sent.
- **Choose who can see it.** *Anyone with the link* — shareable but never
  advertised. Or *anyone, including search engines* for an event you want found.
- **The link is yours until you delete it.** Results stay published through app
  restarts and site restarts. *Delete link* takes the page down immediately and
  removes it from the server, rather than quietly serving results that are no
  longer true. Renaming the tournament afterwards does not move the link.
- **Copy it, or show a QR code.** The link goes to the clipboard in one press.
- **The website draws, the app decides.** The public site renders a precomputed
  snapshot and never calculates a table of its own, so a rule you change cannot
  make two screens disagree.
- **Only what belongs on a match sheet.** Participants, results and standings go
  out. Your tags, audit history and tournament rules stay on your machine.

## Installation

- **Windows:** run the installer and follow the prompts. It is not code-signed, so
  Windows shows "Unknown publisher" — choose *More info → Run anyway*. If an
  older version is installed, uninstall it first: Windows lists it separately and
  the new installer will not overwrite it cleanly.
- **Android:** install the APK over the previous one. It is signed with the same
  key as earlier versions, so it updates in place and your projects are kept.

## Publishing a tournament

Sharing is opt-in and needs no account anywhere:

1. Open **Online preview** in the sidebar.
2. Choose who can see the link.
3. Check the address on screen — it is the tournament's name as a URL.
4. Press **Activate link**, then copy it or show the QR code.

Afterwards, **Update results** sends the current results again. Changing the
visibility is pushed at once.

To stop, press **Delete link**. The page stops working immediately and is removed
from the server.

The address is created when you activate and then belongs to that link: renaming
the tournament later does not move a link you have already handed out, and
*Delete link* always revokes exactly that address. If you want a different
address, delete the link and rename the tournament first.

Only participants, matches and standings are sent — never your tags, notes, audit
history or tournament rules.

## Upgrading

- Existing projects open unchanged. Sharing is new and off until you press its
  button, so nothing is published until you ask for it.
- A tournament that is only ever used offline behaves exactly as before: no token,
  no address, no internet connection required.
- To move projects to another machine: `Export → Save .top.json`, then
  `Import / Recovery`.

## Known limitations

- Installers are **not code-signed**.
- The built-in publish key ships inside the app, so anyone holding a copy can
  publish on this site. That is acceptable for results you can re-send, and is
  not something to build on for anything worth stealing. A custom token, if you
  run your own site, is stored in the app's settings — as protected as the profile
  directory it lives in.
- Sharing is manual: results update when you press **Update results**. There is no
  automatic republishing yet, so a match scored live is not on the page until you
  send it again.
- Tables scroll inside their own frame on a phone; they are not reshaped into cards.
