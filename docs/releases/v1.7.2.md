# Tournament Organizer 1.7.2

Released 2026-10-04 · [Download](#download) · [Changelog](../CHANGELOG.md)

A patch about **language**: the public page now speaks the language the organizer
publishes in — English, Polish, German or Spanish — all the way down, including the
documents and the metadata.

## Highlights

- **A page in your language.** Navigation, statuses (*Played*, *Rozegrany*,
  *Gespielt*, *Jugado*), standings columns, empty states, the documents page and its
  print sheets, the PDF headings, the CSV headings, and the title and description a
  search engine reads. `<html lang>` and `og:locale` follow the event.
- **Dates the way your language writes them.** `2 paź 2026`, `2. Okt. 2026`,
  `2 oct 2026`, `2 Oct 2026` — always in UTC, exactly as entered in the app.
- **A page left open stays in language.** The "updated 3 hours ago" line is written by
  the browser after the page has been sitting there; it now uses the same words the
  server used, handed to it by the page rather than written a second time.
- **Translated, not pluralised.** A team reads as *Drużyny* in Polish and
  *Mannschaften* in German, not as an English word with a letter glued on.

## Installation

- **Windows:** run the installer. It is not code-signed, so Windows shows "Unknown
  publisher" — choose *More info → Run anyway*. Uninstall an older version first.
- **Android:** install over the previous one; it is signed with the same key, so
  projects are kept.

## Publishing a tournament

Unchanged: **Online preview** → choose who can see the link → check the address →
**Activate link**. Results are then published automatically. **Update results** sends
them again at once; **Delete link** removes the page from the server for good.

Events published before this release keep their English page — a snapshot with no
language, or in one nobody has written yet, reads in English rather than showing a raw
label. Nothing needs re-sending.

## Known limitations

- The four languages are the site's **own** sentences. The sport's vocabulary — a *Set*,
  a *Court*, a *Team* — still comes from the desktop app, in the words you chose there.
- PDFs use the base-14 fonts and WinAnsi encoding: English, Polish, German and Spanish
  are complete, but a name in a script outside Latin-1 loses its diacritics.
- Installers are **not code-signed**.
