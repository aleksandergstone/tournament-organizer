# Tournament Organizer 1.3.0

Released 2026-09-28 · [Download](#download) · [Changelog](../CHANGELOG.md)

The app now speaks your language. The whole interface, every message it produces
and every document it prints are available in **English, Polish, German and
Spanish** — offline, as always.

## Highlights

- **Four languages, one switch** — Settings → Appearance → Language offers
  *System* plus the four languages by endonym. The choice is saved with your
  preferences and applies immediately: no restart, no internet.
- **Translated documents, not just buttons** — the PDF, the printout and the CSV
  are produced in the selected language: section titles, column headings, status
  words, tie-break names and dates (month names, weekday names and date order
  all follow the language).
- **Translated engine messages** — validation, result entry, import/recovery,
  LAN sharing, QR deep links and the desktop bridge report in the selected
  language, not just the labels around them.
- **One dictionary as the single source of truth** — English is canonical and the
  other three are checked against it at build time, so a missing translation can
  never reach a release.

## Fixes

- Round names and the grand final no longer depend on English text: the final is
  identified by its round number, so brackets behave identically in every
  language.
- Table labels that were baked in at load time (place types, document types,
  status words, tie-break names) now follow a language change made in the same
  session.

## Known limitations

- Round names and group names generated by an earlier version keep the language
  they were generated in until the bracket is generated again.
- The project history keeps its technical entries (e.g. `result.edit …`); it is
  a log, not copy.
- Installers are **not code-signed** and the macOS app is not notarized (see
  Installation).

## Installation

- **Windows:** run the installer and follow the prompts. The installer is not
  code-signed, so Windows shows “Unknown publisher” — choose *More info → Run
  anyway*.
- **macOS:** open the disk image and drag the app into Applications. Not
  notarized: the first launch needs right-click → *Open*.
- **Linux:** `chmod +x Tournament-Organizer-1.3.0-linux-x86_64.AppImage` and run it.

## Upgrading

- Existing projects open unchanged; the language preference is part of your
  settings and is stored with the project.
- To move projects to another machine: `Export → Save .top.json`, then
  `Import / Recovery`.
