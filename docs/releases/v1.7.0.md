# Tournament Organizer 1.7.0

Released 2026-10-04 · [Download](#download) · [Changelog](../CHANGELOG.md)

A release about the **public page**. The app itself changes only in the places that
publish results; what a spectator opens at the shared link is a different product from
the one they saw before.

## Highlights

- **The event, first.** Every public page opens with the event's name, sport, format,
  dates and venue, whether it is a **tournament** or a **league**, and a status that
  says plainly whether it is *Live*, *Not started*, *In progress* or *Completed*.
- **Live means live.** A match being scored in the desktop app shows as *Live* with
  the score in the largest type on the page. A kick-off that has passed reads as
  *Delayed*, a match stopped mid-way as *Interrupted*, and the footer says how long
  ago the results were updated — ticking while the page stays open.
- **Leagues are read as leagues.** A league shows its table and its fixtures grouped
  by round or matchday, and is not handed a bracket. A knockout shows its bracket and
  no table. The page decides from the event's own format, not from the shape of its
  data — which is how a round robin stopped being offered a "bracket" made of its own
  matchdays.
- **Documents.** Every published event has a **Documents** page with real files:
  standings, fixture list, participants and an event summary as CSV, each with a name
  and a line saying what is inside. Only documents the event can fill are offered — a
  knockout has no standings file to offer. There is also a print sheet: the browser's
  own "save as PDF" produces the standings, bracket or fixtures on white paper.
- **Written for a reader.** Counted words are pluralised properly, discipline wording
  comes from the app, every page has its own meta description, and the event name
  appears in every title.
- **Readable on a phone, and at night.** Wide tables scroll inside their own frame,
  the current match is legible at arm's length, and the page follows a device that
  prefers a dark screen.
- **Honest when the connection drops.** If the live stream is interrupted, the page
  says so and keeps itself up to date by polling, rather than leaving a "Live" dot
  that has quietly stopped meaning anything.

## Installation

- **Windows:** run the installer and follow the prompts. It is not code-signed, so
  Windows shows "Unknown publisher" — choose *More info → Run anyway*. If an older
  version is installed, uninstall it first.
- **Android:** install the APK over the previous one. It is signed with the same key
  as earlier versions, so it updates in place and your projects are kept.

## Publishing a tournament

Unchanged from 1.6.0, and still one button: open **Online preview**, choose who can
see the link, check the address, press **Activate link**. Nothing is sent before that
press. **Update results** re-sends the current results; **Delete link** removes the
page from the server and stops it working.

## Upgrading

- Existing projects open unchanged, and nothing you published in 1.6.0 needs re-sending:
  the pages re-render from the same published snapshot.
- A tournament used only offline behaves exactly as before — no token, no address, no
  internet connection required.
- To move projects to another machine: `Export → Save .top.json`, then
  `Import / Recovery`.

## Known limitations

- Installers are **not code-signed**.
- Sharing is still manual: results update when you press **Update results**. There is
  no automatic republishing yet.
- Documents are CSV files plus a print sheet rather than pre-built PDF files: the same
  rows, produced by the browser's own print command.
- The public page is written in English, with the sport's own words taken from the
  desktop app (a *Set*, a *Court*, a *Team*).
