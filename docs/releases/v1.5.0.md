# Tournament Organizer 1.5.0

Released 2026-10-02 · [Download](#download) · [Changelog](../CHANGELOG.md)

A release about what happens *during* an event, and about the app saying what each
sport actually calls things. You can now score a match as it is played, start from
the sport you are organizing, and print a set of regulations that belong to the
event.

## Highlights

- **Live scoring.** A dedicated screen for the match in front of you: one tap for
  a point, the set ends by itself when the threshold is reached, and the result
  is written straight into the match. Previously you entered the final score
  after the fact, which is exactly when mistakes happen.
- **Sets, counted the way the sport counts them.** A new rule group covers points
  per set, sets needed to win the match, and the two-clear-points rule. Sports
  with no sets at all — football, chess — set the threshold to 0 and the score
  stays a single running total, so nothing irrelevant is asked of you.
- **Start from the sport.** The setup asks for the discipline first. Football
  arrives with 3/1/0 and a penalty draw rule, volleyball with 25 points, three
  sets and no draws, chess with half-point draws and Buchholz as the tiebreak.
  Choose the format afterwards and it still wins on anything the two disagree
  about. Every value stays editable.
- **Seasons and regulations.** Group several events into one running table, and
  keep the tournament rules as a document of their own — printable next to the
  results or on its own sheet.
- **Your names on the printouts.** Standings, match list, schedule, bracket and
  groups can each be renamed, with a document title, a base file name, a date
  format and a time format that apply to everything the app prints.
- **The right word for the place.** A venue is called a pitch, court, table or
  board depending on the sport, rather than one word for everything. The value
  stored in your files stays neutral, so saved projects and QR links are
  unaffected.

## Installation

- **Windows:** run the installer and follow the prompts. It is not code-signed, so
  Windows shows "Unknown publisher" — choose *More info → Run anyway*. If an
  older version is installed, uninstall it first: Windows lists it separately and
  the new installer will not overwrite it cleanly.
- **macOS:** open the disk image and drag the app into Applications. Not
  notarized: the first launch needs right-click → *Open*.
- **Linux:** `chmod +x Tournament-Organizer-1.5.0-linux-x86_64.AppImage` and run it.
- **Android:** install the APK over the previous one. It is signed with the same
  key as earlier versions, so it updates in place and your projects are kept.

## Upgrading

- Existing projects open unchanged. New rule fields fall back to their defaults,
  which means one running total — a set-based event you started before this
  release keeps working exactly as it did.
- Seasons, regulations and document titles are new and empty until you fill them
  in; nothing is invented on your behalf.
- To move projects to another machine: `Export → Save .top.json`, then
  `Import / Recovery`.

## Known limitations

- Installers are **not code-signed** and the macOS app is not notarized.
- Tables scroll inside their own frame on a phone; they are not reshaped into cards.
- Below 320px wide the layout is untested.
- Live scoring is one match at a time; there is no multi-court view yet.
