# Tournament Organizer 1.7.1

Released 2026-10-04 · [Download](#download) · [Changelog](../CHANGELOG.md)

A patch that finishes 1.7.0: the public page keeps itself up to date, looks like the
organizer's event rather than ours, and hands out real PDF files.

## Highlights

- **Results publish themselves.** Turn sharing on and the page keeps up by itself —
  a result reaches spectators a few seconds after you enter it, wherever you are in
  the app. The button on **Online preview** remains, for sending them again.
- **Your branding travels.** The logo, event title, competition line, edition, note
  and accent colour set in **Branding** are published with the event: the page shows
  them, the tabs and links take the accent colour, and a shared link preview carries
  the logo as its image.
- **PDF documents.** Standings, fixtures or matches, participants and an event
  summary — each available as a **PDF** and as a **CSV**, generated by the site from
  the same published results the page shows.
- **A build that cannot ship the wrong app.** The Android build now stops a Gradle
  daemon left over from an earlier run before copying the web bundle, and refuses to
  finish if the bundle inside the APK is not the one just built.

## Installation

- **Windows:** run the installer. It is not code-signed, so Windows shows "Unknown
  publisher" — choose *More info → Run anyway*. Uninstall an older version first.
- **Android:** install over the previous one; it is signed with the same key, so
  projects are kept.

## Publishing a tournament

Unchanged: **Online preview** → choose who can see the link → check the address →
**Activate link**. Results are then published automatically. **Update results** sends
them again at once; **Delete link** removes the page from the server for good.

Everything published in 1.6.0 and 1.7.0 keeps working — the same link, the same
settings, no re-sending required.

## Known limitations

- Installers are **not code-signed**.
- The public page's own sentences are written in English, with the sport's vocabulary
  taken from the desktop app (a *Set*, a *Court*, a *Team*), exactly as before.
