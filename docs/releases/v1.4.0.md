# Tournament Organizer 1.4.0

Released 2026-09-30 · [Download](#download) · [Changelog](../CHANGELOG.md)

**The app is now completely free and always will be.** No Pro edition, no licence
key, no activation, no subscription, no payment. Everything works for everyone.

## What changed

- **1.3.0's paid edition is gone.** It was introduced in 1.3.0 and removed here.
  Nothing that was behind a paywall before 1.3.0 is behind one now.
- **Kiosk display and LAN sync are free again.** 1.3.0 put them behind the
  paywall; they are free in 1.4.0.
- **If you bought a Pro licence in 1.3.0:** nothing further is needed. The app no
  longer checks for a licence, so there is nothing to enter and nothing to
  reclaim. Every Pro feature is unlocked.
- **Optional support note.** A quiet one-line note on the Home screen and in
  Settings → About links to a support page if you would like to help development.
  It is not a modal, blocks nothing, and has one dismiss button.

## Support the project

If the app is useful to you, you can support development at
[the support page](https://example.invalid/support). This is entirely optional and
changes nothing about how the app works — there is no tier, no benefit and nothing
unlocks. The link is configured in one place, `src/support.ts`.

## Known limitations

- Installers are **not code-signed** and the macOS app is not notarized (see
  Installation).

## Download

| Your system | File | Notes |
|---|---|---|
| Windows (x64) | `Tournament-Organizer-1.4.0-win-x64.exe` | NSIS installer |
| macOS (Intel / Apple silicon) | `Tournament-Organizer-1.4.0-mac-<arch>.dmg` | Disk image |
| Linux (x64) | `Tournament-Organizer-1.4.0-linux-x86_64.AppImage` | `chmod +x`, then run |

## Installation

- **Windows:** run the installer and follow the prompts. The installer is not
  code-signed, so Windows shows “Unknown publisher” — choose *More info → Run
  anyway*.
- **macOS:** open the disk image and drag the app into Applications. Not
  notarized: the first launch needs right-click → *Open*.
- **Linux:** `chmod +x Tournament-Organizer-1.4.0-linux-x86_64.AppImage` and run it.

## Upgrading

- Existing projects open unchanged.
- To move projects to another machine: `Export → Save .top.json`, then
  `Import / Recovery`.
