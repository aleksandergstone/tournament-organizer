# Tournament Organizer 1.1.0

Released 2026-09-27 · [Download](#download) · [Changelog](../CHANGELOG.md)

This release turns the app into an **event operations tool**: a hall display, QR
check-in, court scheduling and local-network sync — all working offline, on your
own machines, without an account.

## Highlights

- **Display Mode** — one click opens a big, read-only screen for a projector or TV:
  the current match, what is next, the top five and a live clock. It refreshes itself
  and has no organizer controls, so nobody can break it from the front of the hall.
- **QR codes** — print a check-in code per participant, a code per match and one per
  station. Scanning opens the app directly on that participant or match. Codes are
  generated on the machine; nothing is uploaded and no service is involved.
- **Venue scheduling** — add your courts, tables or stations, then give each match a
  place, a start time and a duration. Double-booking is reported instead of silently
  accepted, and **Fill free slots** plans the day without overlaps.
- **Group → knockout preview** — choose who advances and see the qualifiers, the seeding
  and the bracket that *would* be created. Nothing changes until you confirm.
- **LAN sync** — run a referee machine, a display machine and the organizer laptop on the
  same Wi-Fi. One device shares the project on `http://<ip>:8971`; others receive or send
  it. Merges are per match (newest edit wins, ties stay local), brackets are recomputed
  afterwards, and every merge can be undone.

## Fixes

- Result edits now carry a timestamp, which is what makes conflict-aware merging possible.

## Known limitations

- Sharing needs the **desktop app** (a browser cannot open a port). Receiving and sending
  work from either.
- The first connection from another device triggers the Windows firewall prompt — allow it.
- LAN sync does not merge two devices automatically: press *Receive from it* or wait for an
  incoming push when sharing. Match-level merging only; a simultaneous edit on two devices
  resolves to the newer edit.
- Installers are **not code-signed** and the macOS app is not notarized (see Installation).
- Bracket formats are tested up to 64 participants.

## Installation

- **Windows:** run the installer and follow the prompts. The installer is not code-signed,
  so Windows shows “Unknown publisher” — choose *More info → Run anyway*.
- **macOS:** open the disk image and drag the app into Applications. Not notarized: the
  first launch needs right-click → *Open*.
- **Linux:** `chmod +x Tournament-Organizer-1.1.0-linux-x86_64.AppImage` and run it.

## Upgrading

- Project files from 1.0.0 open unchanged; the venue list is an optional addition.
- To move projects to another machine: `Export → Save .top.json`, then `Import / Recovery`.
